# 火锅计价器小程序

用于计算按盘子颜色计价的火锅账单，支持活动折扣、按人配置锅底费、蘸料费、人均金额和账单明细。

## 功能

- 四类盘子计数：铁盘、红盘、黄盘、绿盘
- 折扣选择：无折扣、6.8 折、5.8 折
- 用餐人数调整和人均计算
- 默认锅底单价与每人锅底价自定义
- 蘸料费按人数自动计算
- 长按盘子卡片连续加盘，点击加号触发 Emoji 动效
- 一键重置账单

## 价格规则

默认价格如下：

| 项目 | 单价 |
| --- | ---: |
| 铁盘 | 22 元 |
| 红盘 | 15 元 |
| 黄盘 | 10 元 |
| 绿盘 | 5 元 |
| 锅底 | 12 元/人 |
| 蘸料 | 4 元/人 |

默认折扣为 6.8 折。修改默认锅底单价时，仍沿用旧默认价的人会自动同步到新默认价，已经单独改过的每人锅底价会保留。
